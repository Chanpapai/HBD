# 🎂 Happy Birthday Website

เว็บไซต์วันเกิดส่วนตัว: แกลเลอรีรูปให้ดาวน์โหลด, ซองของขวัญ + QR รับของขวัญ,
ฟอร์มอวยพร และกำแพงคำอวยพรที่ต้องผ่านการอนุมัติจากแอดมินก่อนแสดงผล

สร้างด้วย **Next.js 14 (App Router)** + **Tailwind CSS** + **Supabase**
(Database + Storage + Auth) — ใช้งานได้ฟรีทั้งหมด และตั้งค่าได้จาก Chromebook
โดยไม่ต้องติดตั้งอะไรในเครื่อง (ใช้ผ่านเว็บเบราว์เซอร์ล้วน ๆ)

## 🆕 อัปเดตล่าสุด

1. **ธีมสีเปลี่ยนเป็นฟ้า-ม่วง** — ไล่เฉดตั้งแต่หน้าปกจนถึงปุ่มหลัก
   (แก้ที่ `tailwind.config.js` และ `app/globals.css`)
2. **ข้อมูลเจ้าของวันเกิด** แสดงบนหน้าแรก แก้ไขได้ในหน้า Admin → เนื้อหาหน้าแรก
   (ค่าเริ่มต้น: นาย ปรเมศ ชาญป่าไพร / ชื่อเล่น 9 / เกิด พ.ศ. 2552)
3. **แกลเลอรีอ่านรูปจากโฟลเดอร์ `/public/gallery/` อัตโนมัติ** — ก็อปรูปใส่โฟลเดอร์
   แล้ว deploy ใหม่ก็พอ ไม่ต้องอัปโหลดผ่านหน้า Admin (ดูรายละเอียดในข้อ 5 ด้านล่าง)
   รูปจากโฟลเดอร์นี้จะแสดงรวมกับรูปที่แอดมินอัปโหลดผ่าน Supabase ตามปกติ
4. **รูปหน้าปก** ยังเป็น Placeholder น่ารัก ๆ (วงแหวนไล่เฉด + ไอคอนเค้ก) จนกว่าจะ
   อัปโหลดรูปจริงผ่านหน้า Admin — ไม่ต้องแก้โค้ดตอนเปลี่ยนรูป
5. รวมการแก้ไขปัญหา deploy ที่เคยเจอไว้ในโค้ดชุดนี้แล้ว (ฟอนต์โหลดผ่านลิงก์แทน
   next/font, หน้าเว็บ render แบบ dynamic ไม่ prerender ตอน build, Supabase client
   ไม่ throw error ถ้า env หาย)

## 🆕 อัปเดต v2 (แก้ปัญหา + ฟีเจอร์ใหม่)

**สิ่งที่ต้องทำครั้งเดียวหลังอัปโหลดโค้ดใหม่:** เปิด Supabase → SQL Editor → วางไฟล์
`supabase/fix_v2.sql` → Run (รันซ้ำกี่ครั้งก็ปลอดภัย) — ขั้นตอนนี้แก้ปัญหาที่ทำให้
คำอวยพรไม่โผล่ใน Admin

   อนุมัติแล้ว แอดมินจึงมองไม่เห็นรายการ "รอตรวจ" ตอนนี้ Admin เห็นทุกสถานะ พร้อมชื่อ
   ข้อความ วันที่ เวลา และปุ่ม อนุมัติ / ซ่อน / ลบ (มีข้อความแจ้งผลและ error ที่เข้าใจง่าย)
2. **ปุ่ม "ดาวน์โหลดรูป" ดาวน์โหลดไฟล์จริง** ทั้ง Android / iPhone / คอมพิวเตอร์
   โดยไม่เปลี่ยนหน้า (มีปุ่ม "บันทึก/แชร์" เพิ่มบนมือถือที่รองรับ เพื่อบันทึกลงอัลบั้ม)
3. **Gallery เลือกหลายรูป / ดาวน์โหลดทั้งหมด** เป็นไฟล์ ZIP เดียว `birthday-photos.zip`
   พร้อมแถบความคืบหน้า
4. **รูปบุคคล PNG พื้นหลังโปร่งใส** ไม่มีวงกลม/กรอบ เรียงบนหน้าแรก + ฝนรูปลอยลงมาช้า ๆ
   สุ่มตำแหน่ง ขนาด ความเร็ว (วางรูปที่ `public/profile/`)
5. **ให้ของขวัญ = QR 2 ใบแยกการ์ด** "สแกนธนาคาร" และ "สแกน TrueMoney" พร้อมข้อความ
   `พร้อมเพย์ / TrueMoney: 0645742422` — Admin เปลี่ยนรูป QR และข้อความได้ทั้งสองใบ
   (ใส่รูป QR เริ่มต้นไว้ที่ `public/qr/` ให้แล้ว)

## 1. โครงสร้างหน้าเว็บ

| เส้นทาง | หน้าที่ |
|---|---|
| `/` | หน้าแรก: รูปเจ้าของวันเกิด, หัวข้อ, ปุ่มหลัก 3 ปุ่ม, กำแพงคำอวยพร |
| `/gallery` | แกลเลอรีรูป ดูเต็มจอ + ดาวน์โหลด |
| `/gift` | ซองของขวัญ (แตะเปิด) → แสดง QR รับของขวัญ |
| `/wish` | ฟอร์มส่งคำอวยพร (ต้องรออนุมัติ) |
| `/admin` | แผงควบคุม (ต้อง login) จัดการรูป/คำอวยพร/QR/ข้อความหน้าแรก |
| `/admin/login` | หน้าล็อกอินแอดมิน |

## 2. ตั้งค่า Supabase (ทำผ่านเว็บเบราว์เซอร์ล้วน ๆ)

1. ไปที่ [supabase.com](https://supabase.com) → สมัคร/ล็อกอิน → **New project**
   (เลือกแผน Free ได้เลย)
2. เมื่อโปรเจกต์พร้อมแล้ว ไปที่เมนู **SQL Editor** → วางเนื้อหาทั้งหมดจากไฟล์
   `supabase/schema.sql` ที่แนบมา → กด **Run**
   - คำสั่งนี้จะสร้างตาราง `photos`, `wishes`, `settings`, `admin_users`
     พร้อม Row Level Security (RLS) และสร้าง Storage bucket `gallery` กับ `qr`
     ให้อัตโนมัติ
3. ไปที่ **Authentication → Users** → **Add user** → ใส่อีเมล/รหัสผ่านของแอดมิน
   (คนเดียวที่จะเข้า `/admin` ได้)
4. คัดลอก **User UID** ของบัญชีที่เพิ่งสร้าง
5. กลับไปที่ **SQL Editor** รันคำสั่งนี้ (แทน UUID ด้วยของจริง):
   ```sql
   insert into admin_users (user_id) values ('YOUR-USER-UUID');
   ```
6. ไปที่ **Settings → API** → คัดลอกค่า **Project URL** และ **anon public key**
   ไว้ใช้ในขั้นตอนถัดไป

> 🔒 ทุกตารางเปิด RLS ไว้แล้ว: ผู้ชมทั่วไปอ่านได้อย่างเดียว (และเห็นเฉพาะคำอวยพรที่
> อนุมัติแล้ว) ส่วนการเพิ่ม/แก้ไข/ลบข้อมูลทำได้เฉพาะบัญชีที่อยู่ในตาราง
> `admin_users` เท่านั้น

## 3. ตั้งค่าตัวแปรแวดล้อม

คัดลอกไฟล์ `.env.local.example` เป็น `.env.local` แล้วใส่ค่า:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

> ใช้แค่ **anon key** เท่านั้น (ห้ามใช้ service_role key ฝั่งเว็บเด็ดขาด)
> สิทธิ์การเขียน/ลบข้อมูลจริงถูกควบคุมด้วย RLS ที่ตั้งไว้ในขั้นตอนที่ 2 อยู่แล้ว

## 4. Deploy ฟรีด้วย Vercel (ไม่ต้องลง Node บน Chromebook)

**วิธีที่ง่ายที่สุดจาก Chromebook: ผ่าน GitHub เว็บไซต์ + Vercel**

1. ไปที่ [github.com](https://github.com) → สร้าง repository ใหม่ (private ก็ได้)
2. ใช้ปุ่ม **Add file → Upload files** แล้วลากทั้งโฟลเดอร์โปรเจกต์นี้ขึ้นไป
   (เบราว์เซอร์บน Chromebook รองรับการลากทั้งโฟลเดอร์)
3. ไปที่ [vercel.com](https://vercel.com) → สมัครด้วยบัญชี GitHub → **Add New Project**
   → เลือก repository ที่เพิ่งอัปโหลด
4. ในหน้าตั้งค่าก่อน Deploy ให้ใส่ **Environment Variables**:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. กด **Deploy** — รอ 1-2 นาที ก็จะได้ลิงก์เว็บไซต์ทันที (ฟรี ไม่มีค่าใช้จ่าย)
6. ทุกครั้งที่แก้โค้ดแล้วอัปเดตไฟล์ใน GitHub, Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

> ทางเลือก: ถ้าอยากรันทดสอบก่อน สามารถเปิด **Linux (Crostini)** ในการตั้งค่า
> Chromebook แล้วติดตั้ง Node.js เพื่อรัน `npm install && npm run dev` ทดสอบ
> ในเครื่องได้เช่นกัน แต่ไม่จำเป็นต้องทำก็ deploy ได้เลย

## 5. ใช้งานหน้า Admin

1. เข้า `https://<เว็บของคุณ>/admin/login`
2. ล็อกอินด้วยอีเมล/รหัสผ่านที่สร้างไว้ในขั้นตอนที่ 2
3. ในแผงควบคุมจะมี 3 ส่วน:
   - **เนื้อหาหน้าแรก & QR** — แก้หัวข้อ/ข้อความ, อัปโหลดรูปหน้าปก, อัปโหลด QR
     รับของขวัญ, ใส่หมายเหตุ (เช่น เลขพร้อมเพย์)
   - **จัดการรูปแกลเลอรี** — อัปโหลด/ลบรูป (JPG, PNG, WebP)
   - **จัดการคำอวยพร** — ดูคำอวยพรที่รอตรวจ กดอนุมัติเพื่อให้ขึ้นกำแพงหน้าแรก
     หรือลบทิ้งได้

## 6. ใส่รูปแกลเลอรีแบบไม่ต้องผ่าน Admin

1. เปิดโฟลเดอร์ `public/gallery/` ในโปรเจกต์
2. ก็อปไฟล์รูป (`.jpg`, `.jpeg`, `.png`, `.webp`) วางในโฟลเดอร์นี้ได้เลย จำนวนเท่าไหร่ก็ได้
3. อัปโหลดไฟล์ขึ้น GitHub ตามปกติ (เหมือนแก้ไฟล์โค้ดทั่วไป) แล้วปล่อยให้
   Vercel/Netlify build ใหม่ให้อัตโนมัติ
4. ตอน build ระบบจะรันสคริปต์ `scripts/generate-gallery-manifest.js` สแกน
   โฟลเดอร์นี้และสร้างไฟล์ `public/gallery-manifest.json` ให้อัตโนมัติ (ไม่ต้อง
   สั่งรันเอง เพราะผูกไว้กับขั้นตอน `npm run build` แล้ว)
5. รูปเหล่านี้จะโผล่ในหน้า `/gallery` ทันที รวมกับรูปที่แอดมินอัปโหลดผ่านหน้า
   `/admin` (ผ่าน Supabase Storage) โดยไม่ชนกัน — ดูเต็มจอและดาวน์โหลดได้เหมือนกันทั้งสองแหล่ง

> อยากทดสอบก่อน deploy จริง? รันคำสั่ง `npm run gallery:scan` ในเครื่อง (ถ้ามี
> Node ผ่าน Linux/Crostini) เพื่อสร้าง manifest ดูล่วงหน้าได้

## 7. หมายเหตุด้านความปลอดภัย

- เว็บไซต์นี้ **ไม่เก็บข้อมูลบัตร รหัสผ่านการชำระเงิน หรือข้อมูลธุรกรรมใด ๆ**
  QR Code เป็นเพียงรูปภาพช่องทางรับของขวัญเท่านั้น
- ผู้ชมทั่วไปไม่มีสิทธิ์แก้ไขหรือลบข้อมูลใด ๆ ในระบบ (บังคับด้วย RLS ที่ระดับ
  ฐานข้อมูลและ Storage ไม่ใช่แค่ที่หน้าเว็บ)
- คำอวยพรใหม่ทุกอันจะถูกบันทึกด้วยสถานะ `pending` เสมอ และจะไม่แสดงบนหน้าแรก
  จนกว่าแอดมินจะกดอนุมัติ

## 8. โครงสร้างไฟล์โดยย่อ

```
app/
  page.js              → หน้าแรก
  gallery/page.js       → แกลเลอรี
  gift/page.js           → ของขวัญ
  wish/page.js           → ฟอร์มอวยพร
  admin/page.js          → แดชบอร์ดแอดมิน
  admin/login/page.js    → ล็อกอินแอดมิน
components/              → UI ที่ใช้ร่วมกัน (ปุ่ม, การ์ด, คอนเฟตตี้, ซองของขวัญ ฯลฯ)
components/admin/        → ส่วนจัดการของแอดมิน
lib/supabaseClient.js     → Supabase client (ฝั่งเบราว์เซอร์)
lib/useAdminSession.js    → hook เช็คสถานะล็อกอิน/สิทธิ์แอดมิน
supabase/schema.sql        → SQL ตั้งค่าตาราง + RLS + storage ทั้งหมด
scripts/generate-gallery-manifest.js → สแกน public/gallery สร้าง manifest ตอน build
public/gallery/            → ★ วางไฟล์รูปแกลเลอรีที่นี่โดยตรง ไม่ต้องผ่าน Admin
public/profile/            → รูปบุคคล PNG พื้นหลังโปร่งใส (หน้าแรก + ฝนรูป)
public/qr/                 → รูป QR เริ่มต้น (ธนาคาร / TrueMoney)
lib/download.js, lib/zip.js → ระบบดาวน์โหลดไฟล์จริง + สร้าง ZIP
supabase/fix_v2.sql        → ★ รันครั้งเดียวเพื่อแก้สิทธิ์ Admin เห็นคำอวยพร
```

ปรับสี/ฟอนต์ได้ที่ `tailwind.config.js` (โทนสีฟ้า-ม่วงธีมวันเกิด — ชื่อ key สี
ในโค้ดยังคงเดิม เช่น `pink`, `gold`, `mint` แต่ค่าสีจริงเปลี่ยนเป็นฟ้า-ม่วงแล้ว)
