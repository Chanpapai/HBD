# 🧑‍🎤 โฟลเดอร์รูปบุคคล (PNG/WebP พื้นหลังโปร่งใส)

ก็อปรูปบุคคลที่ตัดพื้นหลังแล้ว (.png, .webp, .jpg) ใส่ในโฟลเดอร์นี้ แล้ว deploy ใหม่
- หน้าแรกจะแสดงเรียงกันเป็นแถว (ไม่มีวงกลม ไม่มีกรอบ) สูงสุด 5 รูปแรก
- ทุกรูปจะถูกนำไปทำเป็น "ฝนรูป" ค่อย ๆ ลอยลงมาด้านหลังเนื้อหา สุ่มตำแหน่ง/ขนาด/ความเร็ว

เรียงตามชื่อไฟล์ (profile-1, profile-2, ...) — แนะนำให้ย่อรูปให้กว้างไม่เกิน ~800px
เพื่อให้เว็บโหลดเร็ว (ไฟล์ละไม่เกิน ~100KB จะดีที่สุด)
