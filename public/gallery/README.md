# 📸 โฟลเดอร์นี้ = แกลเลอรีรูปภาพ

**วิธีใช้:** ก็อปไฟล์รูป (.jpg, .jpeg, .png, .webp) วางในโฟลเดอร์นี้โดยตรง
แล้ว deploy เว็บไซต์ใหม่ (push ขึ้น GitHub แล้วปล่อยให้ Vercel/Netlify build ให้)

ระบบจะสแกนไฟล์ในโฟลเดอร์นี้อัตโนมัติทุกครั้งที่ build (ดูสคริปต์
`scripts/generate-gallery-manifest.js`) แล้วนำไปแสดงในหน้า Gallery ให้เอง —
**ไม่ต้องแก้โค้ด ไม่ต้องอัปโหลดผ่านหน้า Admin**

รูปในโฟลเดอร์นี้จะแสดงรวมกับรูปที่แอดมินอัปโหลดผ่านหน้า `/admin` (ผ่าน
Supabase Storage) โดยอัตโนมัติ ใช้ควบคู่กันได้ทั้งสองทาง

> ไฟล์ `.gitkeep` ในโฟลเดอร์นี้มีไว้ให้ Git เก็บโฟลเดอร์ว่างไว้ได้ ลบทิ้งได้เมื่อมีรูปแล้ว
